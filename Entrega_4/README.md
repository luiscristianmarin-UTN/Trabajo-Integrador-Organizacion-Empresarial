# Entrega 4 - Gestión de Proyectos y Requerimientos

## Proyecto
Code Nexus

## Objetivo
Documentar la gestión de proyectos y requerimientos
mediante GitHub, incluyendo historias de usuario,
seguimiento de tareas y trazabilidad de cambios.

## Seguimiento
Se utiliza GitHub Projects para organizar las cinco
historias de usuario y registrar sus cambios de estado.

## Control de versiones
Los cambios de esta entrega se desarrollan en la rama
entrega-4-code-nexus para su posterior revisión e
integración mediante Pull Request.
