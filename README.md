### Declaración de transparencia sobre el uso de IA

El proyecto Code Nexus lo desarrollé de manera individual como parte del Trabajo Práctico Integrador de Organización Empresarial.

Durante la Entrega 4 utilicé ChatGPT como herramienta de asistencia técnica y orientación para comprender las funcionalidades de GitHub, registrar commits, gestionar ramas y Pull Requests, organizar documentación y elaborar propuestas de indicadores y diagramas.

Realicé personalmente las operaciones en GitHub, supervisando y decidiendo cada paso del proceso.

No se realizó una revisión humana por pares, dado que el trabajo fue individual. La asistencia de ChatGPT no se presenta como equivalente a dicha revisión.

El diagrama BPMN lo generé con asistencia de ChatGPT y requiere validación de su notación formal antes de considerarse definitivo.
